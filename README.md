# Upload-server

Toto je web v repozitári s HTML stránkami (`templates/`) a CSS (`static/`).

## Spustenie

```bash
cd /workspace/Upload-server
python3 server.py
```

Potom otvor:

- `http://localhost:5000/index.html` (hlavná stránka)
- `http://localhost:5000` (funguje tiež)

## Prihlásenie

- prístupový kľúč: `T4B-Q7L`
- profil: `Profil 1`
- číslo v hornom rohu po prihlásení: `071`

## Funkcie

- login cez prístupový kľúč,
- profilová stránka s číslom profilu,
- upload súboru + povinný popis,
- uloženie do `uploads/profil1/`,
- zoznam súborov so stiahnutím,
- odhlásenie.
